# Server Rack

A DIY, modular and expandable server rack designed for homelab projects.

- DIY
- Modular
- Expandable
- And more...

## Features

- Modular design
- Uses standard U rack units
- Default mounting holes: M3
- M6 support planned for future versions
- Easy to expand and customize

## Status

- In development

## Based On

- Lab Rax by [mklements](https://makerworld.com/pt/@mklements)
- KWS Rack V2 by [Ilan Kushnir](https://makerworld.com/pt/@ilanKush)

## Materials

- M3 screws
- M6 screws
- 3D printer

## Tools Used

- Fusion 360
- OrcaSlicer
